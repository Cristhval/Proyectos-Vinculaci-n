# Politica de Seguridad

## Reportar Vulnerabilidades

Si descubres una vulnerabilidad de seguridad, por favor reporatala
a traves de un issue privado o contactando directamente al equipo
de desarrollo.

**NO** crees issues publicos para vulnerabilidades de seguridad.

## Respuesta

- Acknowledgment dentro de 48 horas
- Evaluacion de severidad dentro de 1 semana
- Correccion y release segun severidad
