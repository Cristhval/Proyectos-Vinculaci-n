# Codigo de Conducta

## Nuestro Compromiso

Nos comprometemos a hacer de la participacion en este proyecto una
experiencia libre de acoso para todos, sin tolerar discriminacion
de ningun tipo.

## Estandares de Comportamiento

- Uso de lenguaje respetuoso y considerado
- Respeto a puntos de vista y experiencias diversas
- Aceptar la critica constructiva de buena fe
- Enfocarse en lo que es mejor para la comunidad
- Mostrar empatia hacia otros miembros del equipo

## Alcance

Este codigo de conducta aplica a todos los espacios del proyecto,
incluyendo repositorio, issues, pull requests y comunicaciones
del equipo.

## Incidentes

Para reportar incidentes, contactar al equipo de desarrollo
a traves de los issues del repositorio con la etiqueta `conduct`.

## Atribucion

Este codigo de conducta esta adaptado del
[Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
