# Changelog

Todas las versiones notables de este proyecto seran documentadas en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es/1.1.0/)
y este proyecto adherido a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2026-07-14

### Added

- Sistema completo de gestion de proyectos de vinculacion
- Ciclo de vida de proyectos con 8 estados (BORRADOR a CERRADO)
- Formulacion de proyectos con metodologia de marco logico (6 pasos)
- Gestion de convenios interinstitucionales con 7 estados
- Modulo de seguimiento: avances, evidencias e informes
- Dashboard ejecutivo con graficas interactivas (ApexCharts)
- Exportacion de reportes a PDF y Excel
- Sistema de auditoria con trazabilidad completa
- Centro de notificaciones y alertas automaticas
- Formatos institucionales UNL descargables
- Autenticacion JWT con refresh automatico
- Control de acceso basado en roles (RBAC) con 5 roles
- Dashboards personalizados por rol
- API REST documentada con Swagger/ReDoc
- Frontend React 19 + TypeScript + Vite + Tailwind CSS
- Backend Django 6 + Django REST Framework 3.17
- Diseno responsivo para multiples dispositivos
- Git Flow con branches feature por modulo

### Fixed

- Correcciones globales del sistema backend y frontend
- Correccion de diseno y UX en modulo de convenios
- Correccion de bugs en sistema de alertas
- Correccion de errores en creacion de avances y evidencias
- Correccion de diseno en auditoria y badges

### Changed

- Refactorizacion de codigo en modulo de convenios
- Actualizacion de dependencias del backend y frontend
- Mejora de diseño en dashboard y reportes
